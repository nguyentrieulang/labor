# P1 – Nền móng: CSDL, nhận tin, lệnh chat – Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dịch vụ Python `labour` nhận tin từ bể bot Telegram, khử trùng lặp, kiểm truy cập, đăng ký nhóm bằng /start, nhận diện ý của chủ nhóm bằng luật tất định và trả lời các lệnh chat – chưa gọi AI.

**Architecture:** Modular monolith (HLD Hình 11): `labour.core` chỉ import `labour.ports`; `labour.adapters` (telegram, storage) triển khai ports; `labour.app` ghép nối. Core không gửi tin trong transaction: hàm core ghi CSDL rồi trả `list[Outgoing]`, ingest gửi sau khi commit qua `Outbox`.

**Tech Stack:** Python 3.12, uv, aiogram 3, SQLAlchemy 2 (sync) + Alembic, SQLite WAL, pydantic 2, PyYAML, pytest + pytest-asyncio.

**Spec:** `docs/2026-11-19-LLD-agent-team-v2.2-v0.2.docx` (LLD v0.2). Lộ trình: `docs/plans/2026-11-19-lo-trinh-trien-khai.md`.
